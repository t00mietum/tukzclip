# tukzclip

A clipboard keeper for the tukzedo desktop. It sits in the system tray, keeps what you copied after the app you copied it from closes, and passes the clipboard between Wayland and X11 apps.

## Status

Not started. Requirements are in [project/backlog.md](project/backlog.md).
